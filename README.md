# Symulator Młodego Gniewnego

Drift po własnym torze. Auto to **BMW M3 Coupe (E46)** — model [Mona x Supercars](https://sketchfab.com/Car2022), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Dźwięki są CC0. Szczegóły w `LICENSES.md`.

## Sterowanie

- Pad (DualSense, Gamepad API): R2 gaz, L2 hamulec, lewy drążek, krzyżyk albo kwadrat — ręczny, trójkąt albo Options — reset.
- Klawiatura: strzałki albo WASD, spacja — ręczny, R — reset.
- Dotyk: lewa połowa kieruje, po prawej Gaz, Hamulec, Ręczny.
